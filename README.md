# Muse Music

Muse Music is a rhythm-based 3D game developed as a capstone project using the Godot Engine and GDScript. The game focuses on note-timing gameplay, score tracking, combo mechanics, and a polished result system.

This project is currently under development and is intended as a university capstone game project.

## Project Information

- Project Type: Capstone Project
- Engine: Godot 4
- Language: GDScript
- Genre: Rhythm / Music Game
- Status: In Development

## Project Overview

Muse Music is a rhythm game where the player must hit notes in time with the music. The objective is to maintain accuracy, build combo streaks, and avoid misses that reduce stamina. At the end of the song, the player is evaluated based on their performance.

The game includes:
- main menu
- song selection
- settings / pause menu
- gameplay loop
- score and combo system
- HP system
- result screen and rank evaluation

## Features

- Rhythm note gameplay
- Real-time score calculation
- Combo tracking
- Accuracy and rank evaluation
- Miss penalty and stamina reduction
- Progression through menu scenes
- 3D gameplay environment
- Custom game logic built in GDScript

## Game Objective

The player must hit notes as they reach the target area. Successful hits increase score and combo, while missed notes reduce stamina. If stamina reaches zero, the run ends and the result screen is displayed.
